Tetris (project TETR)

Live HTML documentation of work already shipped in this repository. The same map lives as comments in index.html (TETR-62). This page makes that documentation readable in a browser (TETR-63).

Toolchain (TETR-61, TETR-60)

  • TypeScript + Vite 8 local-first static frontend (no required backend)
  • Vitest for src/**/*.test.ts, ESLint + Prettier, Node 20 via .nvmrc
  • npm run dev / test / lint / build / preview; production assets in dist/

Game engine (src/game)

  • 10x20 visible matrix plus 4 buffer rows
  • Seven tetrominoes (I O T S Z J L) with Super Rotation System kicks
  • Hold, 5-piece next queue, seven-bag randomizer
  • DAS/ARR handling, soft drop, hard drop, 180 rotate
  • Guideline scoring: line clears, T-Spins (including mini), combos, back-to-back
  • Level gravity curve, lock delay with reset limit, line-clear animation
  • Block-out and top-out detection
  • Play modes: Marathon, Sprint 40, Ultra timed, Zen (no fail), Versus garbage

Player shell (src/player, src/ui, src/runtime)

  • HUD: score, level, lines, combo, back-to-back, high score, mode timer
  • Pause overlay and game-over summary
  • Remappable keys, touch controls, DAS/ARR settings
  • Persistence (local storage), music/SFX, themes, colorblind palette, contrast, type scale
  • Line-clear and level-up effects, last-game replay, local per-mode leaderboard
  • Responsive breakpoints, requestAnimationFrame loop, input paint timing
  • Offline single-player (service worker + PWA manifest)

Social stretch (src/social)

  • Local and online versus with garbage attacks; spectator view
  • Daily seeded challenge, accounts + cloud save, achievements
  • Global leaderboard with server-side score validation

Bootstrap

  • #app is the mount for hub, playfields, settings, ranks, account, trophies
  • /src/main.ts wires engine + player session + social backend + frame loop
  • /public/manifest.webmanifest and /public/sw.js enable standalone/offline play

Source of truth in git: comments on index.html plus this static page at /documentation.html.
